# 张健航 · AI 产品经理

个人网站：https://z2302743489.github.io/

以暖纸色、酒红色和淡紫色构成视觉系统，包含日落摄影首屏、个人介绍、可切换的产品探索页签、产品思考和 GitHub 联系入口。探索界面为明确标注的概念示意，尚未填入真实项目经历。

## 修改网站

- `index.html`：文案、导航和页面内容。
- `style.css`：视觉样式、布局和手机适配。
- `app.js`：探索页签、键盘导航、网站链接复制和滚动导航样式。
- `assets/golden-hour.jpg`：AI 生成的首屏氛围图。
- `assets/ASSETS.md`：图片来源说明与完整生成提示词。

图片中的匿名人物为氛围示意，不是张健航的本人照片。
