# Archived logo sources

24 complete monochrome SVGs are from the LobeHub lobe-icons repository at commit `ea434b96e75813517b377825e01c0df61dee8836`. The original MIT LICENSE and static-SVG README are archived under `lobehub/`. Six legacy tool SVGs are recovered verbatim from the original embedded sources in the existing v1 builder, with their existing source URLs and licenses recorded individually in `index.json`.

Run `node scripts/build_tool_logos_v2.mjs` to reproduce all PNGs without a network connection. `node scripts/fetch_tool_logos_v2.mjs` is a separate optional fetch step; `--refresh` downloads pinned originals again and `--offline` validates/rearchives local files only.
