为谁，解决什么问题？

从概念展示页扩展为可以逐项了解项目用途、产品取舍、原作归属与验证边界的作品集。

使用者

希望了解张健航项目实践、产品思考与合作方式的访客。

遇到的问题

只看项目名字与封面，难以判断具体做了什么、哪些是定制工作，以及演示能证明什么。

核心功能

八个项目入口

用封面、一句话介绍与分类筛选，快速找到感兴趣的项目。

独立项目详情

逐项说明用途、目标用户、功能与设计取舍，并提供源码链接和原作归属。

可以体验的演示

结合实际网页、视频、固定问答和流程导览，展示每个项目如何使用。

设计中的取舍

先说清项目是什么

让访客从一句话理解用途，再按需阅读细节，减少抽象标签。

让操作帮助理解

用可点击的实际页面或示例说明流程，同时标清示例与完整软件的关系。

静态页面保持轻量

内容由 JSON 维护，直接托管在 GitHub Pages，无需账户或后端服务。
