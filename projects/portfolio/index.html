Overview

一个收录张健航个人介绍和八个公开项目的作品网站，每个项目都有详情页和演示。

首页展示精选项目，完整项目、个人介绍和联系入口分开浏览。

给谁用
想了解张健航做过哪些项目、具体改了哪些内容的访客。
遇到的问题
只有名称和封面时，很难看清软件用途、具体改动和演示范围。

Features

精选与完整项目

首页先看精选项目，完整作品页收录全部八个项目。

详情与演示

八个项目各有详情页，结合真实网页、视频、固定问答或流程导览说明用法。

个人介绍与联系

个人介绍和联系信息各有独立页面，源码与原作归属保留在对应项目中。

Decisions

首页先写用途

项目行先用短句说明软件是什么，再进入详情查看功能和取舍。

按项目选择演示

能展示实际页面或视频的保留原素材，固定示例同时说明与完整软件的区别。

用 JSON 维护内容

项目资料集中保存在 JSON 中，生成静态页面后托管到 GitHub Pages，无需账户或后端。

Current Status

静态作品网站，保留八个项目的详情与演示。
