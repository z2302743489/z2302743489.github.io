Overview

一个基于 OpenMausBot 定制的个人 AI Agent 桌面版，可连接模型处理任务，配有六款 Fat 主题头像。

沿用上游的多机器人和工具调用能力，统一头像与动画，移除推广入口并区分个人版设置。

给谁用
想在桌面配置模型，用多个机器人处理对话、文件和工具任务的个人用户。
遇到的问题
更换主题后，聊天、侧边栏和资料页的头像要保持一致，旧头像设置也得兼容。

Features

六款 Fat 头像

果冻、弹弹、困困、吃货、国王和太空胖胖统一用于聊天、侧边栏与资料页。

沿用上游 Agent 功能

保留多机器人、团队任务、文件处理和工具调用，具体能力取决于所配模型与服务。

头像动画与偏好

本地播放呼吸、弹跳、摇晃和漂浮动画，保存头像选择，并支持减少动态效果。

Decisions

标明定制范围

基于 OpenMausBot 0.1.143 修改，保留许可、NOTICE 和修改记录，标明上游 Agent 能力的来源。

兼容旧头像设置

旧内置头像回退到 Fat 主题，用户上传的图片仍可使用。

区分个人版配置

桌面设置与数据目录使用个人版名称；从源码启动服务时仍需显式指定数据目录。

Current Status

定制源码已公开，README 记录了 macOS Apple silicon 的验证范围。

Tools
