为谁，解决什么问题？

在保留上游 Agent 工作能力的基础上，统一角色形象与个人使用体验，清理原有品牌推广入口。

使用者

希望在桌面上配置自己的模型，并以多个机器人处理对话、文件与工具任务的个人使用者。

遇到的问题

通用桌面 Agent 的形象与推广入口不一定符合个人习惯，多处头像与旧配置也需要保持一致。

核心功能

六款统一头像

果冻、弹弹、困困、吃货、国王和太空胖胖用于聊天、侧边栏与资料页。

个人工作方式

沿用上游多机器人、团队任务、文件与工具调用能力，实际能力依赖配置的模型与服务。

本地动画与偏好

头像使用本地呼吸、弹跳、摇晃和漂浮动画，支持保存选择及减少动态效果。

设计中的取舍

明确上游归属

基于 OpenMausBot 0.1.143 定制，保留许可、NOTICE 与修改记录，不将上游 Agent 能力归为独立原创。

兼容旧头像设置

旧内置头像回退到 Fat 主题，同时保留用户上传图片的使用方式。

独立个人版身份

桌面设置与数据目录采用个人版命名，源码服务仍需按说明显式指定数据目录。
