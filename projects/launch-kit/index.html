PRD 体检技术适配后端 MVP正式前端上线收尾

手册 / PRD 模板 / 阶段验收清单

Overview

一套中文开发手册，附 PRD 模板和验收脚本，供非技术产品经理配合 AI 编码工具开发网页 MVP。

把需求、技术方案、开发、界面、上线和收尾分成六步，每步写清要交什么、由谁检查。

给谁用
使用 Mac、想借助 AI 编码工具开发网页 MVP 的非技术产品经理和学生。
遇到的问题
不知道从哪一步开始，也难核对 AI 所说的“已完成”是否有文件、测试和可用页面。

Features

六阶段手册

从 PRD 检查到技术适配、后端 MVP、正式前端、上线和收尾，逐步列出操作。

每步检查项

列出需求范围、生成结果和页面可用性等需要人确认的事项。

模板与交付记录

附 PRD 模板，要求记录截图、访问步骤、检查表、自检输出和模型调用测试。

Decisions

由人确认后继续

需求优先级、结果验收和额外支出由人确认，再继续下一阶段。

把进度存成文件

把项目状态和阶段资料存成文件，方便中断后继续或换用其他编码工具。

按产物核对结果

按阶段产物和自检记录验收，分别记录真实模型调用和模拟结果。
