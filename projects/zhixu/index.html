Overview

一个管理企业文档的 AI 问答网站，回答附带原文引用，可在本机或内网试用。

上传文档后提问，沿引用查看原文片段和对应版本。

给谁用
维护内部资料的管理员，以及查制度、找业务资料的员工。
遇到的问题
资料分散在多份文档里，找到答案后还得核对出处和版本。

Demo

选一个问题，查看员工制度示例中的答案，再展开原文和行号。

Features

上传与版本管理

创建知识库、上传文档、检查解析分块，支持去重、替换版本和停用文档。

检索后回答

结合向量检索、中文稀疏检索和可选重排，关联多个知识库并流式回答。

回查引用原文

保存引用的文档版本和片段快照，记录调用日志，方便核对回答依据。

Decisions

保存引用时的版本

资料更新后仍能回查当时的版本和片段，回答准确性仍需核对。

分开配置模型

LLM、Embedding、Rerank 分开配置，便于替换模型，也多了部署时的配置项。

限定试用范围

角色切换仅用于体验，尚无登录认证，当前限本机或受控内网试用。

Current Status

源码已公开，可在本机或受控内网试用。

Tools

React / TypeScript / Ant Design / FastAPI / LangChain / Qdrant / SQLite / PostgreSQL / Celery / Redis
