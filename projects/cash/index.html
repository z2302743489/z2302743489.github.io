解决什么问题

沿用上游的规划、制作、审查和试玩流程，调整品牌与深浅色创作界面。

给谁用
想试做游戏的创作者、游戏策划和独立开发者。
遇到的问题
代码生成后，构建失败、素材缺失或游戏无法运行，仍需要逐项检查和修复。

具体做了什么

输入玩法与参考

填写玩法描述，附上图片或文件；配置账户与素材服务后开始制作。

分工制作与审查

由应用调度规划、实现与审查角色，并限制修复轮数。

构建与试玩

支持 Web 和 Godot 两条路线，通过本地预览、自动试玩及记录复核检查结果。

几处取舍

限制任务与重试

应用规定各角色的任务和修复轮数，给反复重试设定上限。

用构建和试玩验收

交付前检查正式构建和试玩结果，再核对 AI 的完成声明。

保留作者与提交历史

品牌和界面调整保留 Innate-Labs 的作者归属与提交历史，上游尚未提供明确许可证。

当前状态

macOS 开发者预览版，基于上游项目定制。

用到的工具

Electron / React / TypeScript / Vite / Codex App Server / Web / Godot 4 / GDScript
